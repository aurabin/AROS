## Preservation / Internet Archive

For an immutable snapshot, use a commit-specific GitHub archive URL (replace COMMIT with the commit SHA selected for preservation):

https://github.com/aurabin/AROS/archive/COMMIT.tar.gz

**Warning:** The link above archives the *entire AROS repository*, not only AROS Wizard. To archive only Wizard, export the subtree from a local clone and include the root LICENSE and LEGAL plus any component notices. Check the license and copyright status of any imported art, icons, dependencies or binary artifacts before redistribution.

Upload the resulting archive to https://archive.org/upload/ from an Internet Archive account. Include the source commit SHA, date, license notices, platform support status, build/test evidence and a link to the repository. Do not describe untested platform binaries as working releases.

This document does not imply that an Internet Archive item has been uploaded, nor that Internet Archive endorses the project.
